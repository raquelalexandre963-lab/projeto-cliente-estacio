# Projeto Cliente Estácio

Projeto de conexão PHP + MySQL usando PDO, desenvolvido para a disciplina de Desenvolvimento Web - Estácio.

🔗 **Deploy:** https://projeto-cliente-estacio.vercel.app
🔗 **Teste XAMPP:** https://projeto-cliente-estacio.vercel.app/xampp.php

## 🚀 Tecnologias
- PHP 8 + PDO
- MySQL
- XAMPP
- Vercel
- Git/GitHub

## 📁 Estrutura


## 🔧 Como rodar local (XAMPP)
1. Clone: `git clone https://github.com/raquelalexandre963-lab/projeto-cliente-estacio.git`
2. Mova para `C:/xampp/htdocs/`
3. Crie o banco `test` no phpMyAdmin
4. Acesse: `http://localhost/projeto-cliente-estacio/xampp.php`

## 🔌 Código da Conexão
Conexão corrigida com DSN correto do PDO e tratamento de erro com try/catch.
